# 桌面轻提醒 DesktopReminder

> 一个安静地浮在桌面上、自动收起、自动记住你正在做什么并到点提醒你的多线程工作小助手。
> 原则：**平时不打扰，需要时就在眼前。**

## 这是什么

你正在同时处理多项工作（改文档、下载文件、跑智能体……），一转头去忙别的，就把刚才那件事忘了。
桌面轻提醒会在你切换到其他工作后，把当前软件记成一条任务并开始倒计时；到点后通过
「图标角标 → 自动展开」的两层提醒方式告诉你：**这件事到时间了**。

## 核心特性

- **三态自动收起**：清晰 →（5 分钟无操作）→ 半透明 →（30 秒无操作）→ 小图标，平时完全不挡视线
- **自动识别软件名**：新建任务时自动填入上一个操作的软件名称（内置中文映射表，如 explorer → 文件管理器）
- **两层到点提醒**：图标角标显示数字 → 鼠标移上去自动展开看到详情；过期任务每 5 分钟提醒一次
- **任务管理**：备注、稍后（5/10/15/30 分钟）、完成、已完成恢复/删除
- **深色/浅色主题**：跟随 Windows 系统自动切换
- **便携免安装**：解压即用，Win10 / Win11

## 技术架构

四层单向依赖（改一处不影响其他）：

```
表现层 UI（WPF）       只画界面、收点击，不写业务判断
    ↓
应用层 Core            状态机、任务调度、提醒
    ↓
领域层 Domain          任务模型、到期计算（纯逻辑，可单测）
    ↓
基础设施 Infrastructure Windows API、持久化、日志
```

## 开发环境

- .NET SDK 8.0（长期支持版）
- C# / WPF / MVVM
- xUnit 单元测试

## 构建与测试

```bash
dotnet build DesktopReminder.sln
dotnet test tests/DesktopReminder.Tests
```

## 发布（便携版）

```bash
dotnet publish src/DesktopReminder.App -c Release -r win-x64 --self-contained false -o publish
```
