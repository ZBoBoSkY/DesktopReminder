# ⚡ 桌面轻提醒 (DesktopReminder)

> 一款 Windows 桌面常驻的轻量级任务提醒小软件，解决多线程工作场景下后台任务完成后被遗忘的问题。

## 项目背景

在日常工作中，我们经常同时处理多件事情：正在写文档，同时后台在下载大文件；跑一个智能体任务，5 分钟后就结束了；转码一个视频，需要等半小时……但当我们切换到其他工作后，很容易忘记这些后台任务已经完成了。

**桌面轻提醒**就是为了解决这个问题：添加任务时自动识别当前软件，设定预计完成时间，到点后通过面板高亮、系统托盘气泡和提示音提醒你检查。即使你暂时没空处理，也会周期性地持续提醒，确保不会漏掉任何一项工作。

## 功能特性

### 三态状态机
- **激活态**：面板完全不透明，可交互
- **弱化态**：半透明玻璃效果（默认 35% 透明度），不影响正常浏览，鼠标移上即激活
- **图标态**：收起为小圆钮，完全不占空间，点击才展开

闲置自动降级：鼠标离开 1 分钟 → 半透明，再 30 秒 → 图标。

### 悬浮图标
- 没任务时：纯圆形，简洁不打扰
- 有任务倒计时时：圆形右侧伸出小标签，实时显示最近到期任务的倒计时
- 🔴 红色角标（右上）：已过期未处理的任务数
- 🟢 绿色角标（左下）：正在倒计时的任务数
- 图标态每 5 分钟（可配置）自动展开为半透明面板，周期性提醒

### 任务管理
- 添加任务时自动识别当前前台软件名（如 `Chrome`、`Word`），可追加备注说明具体在做什么
- 预设时长：5 / 10 / 15 / 30 分钟 / 1 小时，支持自定义分钟数
- 到点提醒：条目变琥珀色高亮 + 托盘气泡 + 提示音
- 超时未确认：每 10 分钟升级提醒（"已完成 X 分钟"）
- 任务操作：✓ 确认完成 / ⏱ 稍后提醒（5/10/15/30 分钟后再提醒）
- **回收站**：删除的任务进入回收站（保留 7 天），支持恢复、永久删除、一键清空，防止误删除

### 界面体验
- 始终置顶，亚克力玻璃效果（Win10/11 支持，Win7 自动降级为半透明）
- **标题栏全区域可拖拽**（除 + − × 按钮外），不再只有文字区域
- 窗口可调整大小（右下角拖拽手柄），支持手动拉长和根据任务数自动调整高度
- 任务增多自动增高，长文本自动换行
- **玻璃边框顶部高光**：四向边框亮度不同，模拟玻璃反光质感
- **面板展开弹性动画**：从图标态展开时弹性弹入（OutBack 缓动）+ 透明度淡入
- **空状态矢量图标**：无任务时显示 QPainter 矢量绘制的闹钟图标（青→蓝渐变，56px），放大不失真
- **高 DPI 适配**：2K/4K 高分屏 + Windows 缩放下正确显示
- 默认位置屏幕右上角
- 系统托盘常驻，支持开机自启
- 单实例运行，不会重复启动

### 设置项（图形化配置）
- 周期性提醒间隔（默认 5 分钟）
- 升级提醒间隔（默认 10 分钟）
- 半透明透明度（默认 35%）
- 闲置转半透明时间（默认 60 秒）
- 半透明转图标时间（默认 30 秒）
- 声音提示开关
- 开机自启开关
- 无任务时是否周期性提醒

## 技术栈

- **语言**：Python 3.13
- **GUI 框架**：PySide6 6.11
- **打包工具**：PyInstaller 6.22（onedir 模式，约 64 MB）
- **平台**：Windows 7 / 10 / 11（亚克力效果在 Win10 1803+ 支持，Win7 自动降级为半透明）

> **注意**：Windows 11 的智能应用控制（Smart App Control）可能会阻止未签名的 exe 运行。解决方案：关闭智能应用控制，或使用 `python main.py` 源代码运行，或购买代码签名证书给 exe 签名。

## 项目结构

```
DesktopReminder/
├── main.py                  # 入口与应用控制器（三态状态机、闲置计时、周期性提醒）
├── icon.ico                 # 应用图标
├── DesktopReminder.spec     # PyInstaller 构建配置
├── 使用说明.md               # 用户手册
├── 需求规格说明书.md          # 完整需求规格文档
├── app/
│   ├── glass_panel.py       # 玻璃主面板（任务列表、可调整大小、透明度动画）
│   ├── float_icon.py        # 悬浮图标（颜色角标、倒计时标签）
│   ├── add_dialog.py        # 添加任务二级弹窗
│   ├── settings_dialog.py   # 设置窗口
│   ├── task_manager.py      # 任务管理（计时、稍后提醒）
│   ├── window_monitor.py    # 前台窗口监测后台线程
│   ├── winutil.py           # Windows 原生能力（亚克力、进程名、开机自启）
│   ├── settings.py          # 配置管理
│   ├── tray.py              # 系统托盘
│   └── theme.py             # 主题颜色
└── scripts/
    ├── shot.py              # 截图脚本
    ├── seed_demo.py         # 生成示例任务
    └── make_icon.py         # 生成多尺寸图标
```

## 开发与运行

### 环境准备
```bash
pip install PySide6==6.11.2 pyinstaller==6.22.2
```

### 直接运行
```bash
python main.py
```

### 自测模式
```bash
python main.py --selftest
```

### 打包为 exe
```bash
pyinstaller --noconfirm --clean --onedir --windowed --icon icon.ico --name DesktopReminder main.py
```
打包输出在 `dist/DesktopReminder/`，双击 `DesktopReminder.exe` 即可运行。
