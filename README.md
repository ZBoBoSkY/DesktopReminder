# 桌面轻提醒 DesktopReminder

> 一个安静地浮在桌面上、自动收起、自动记住你正在做什么并到点提醒你的**多线程工作小助手**。
> 原则：**平时不打扰，需要时就在眼前。**

---

## 一、这个软件是干什么的？

日常办公常常是"多线程"的：正在改一个文档，改完要去下载东西；跑一个智能体，5 分钟就结束；等一个下载完成，转身又去忙别的……一旦切走，**就忘了还有任务没处理完**。

桌面轻提醒解决的就是这件事：它把「当前正在做的事」记成一条带倒计时的任务，常驻在桌面最顶层；任务到点后通过多层提醒告诉你"这件事到时间了"，让你在多头绪的工作里**不漏掉任何一项**。

它不是闹钟，也不是待办清单，而是一个"**你工作时的记事贴**"——不打断你，但永远不会让你忘记。

## 二、优点和特点

| 特点 | 说明 |
| --- | --- |
| **轻量常驻、不打扰** | 无边框玻璃卡片 / 圆形小图标悬浮桌面最顶层；不用时自动弱化（清晰 → 半透明 → 小图标三态渐进），完全不挡视线 |
| **自动捕捉软件名** | 新建任务时自动识别"上一个操作的软件"，内置中英文映射表（explorer → 文件管理器、feishu → 飞书、doubaowork → 豆包工作……），不用手打软件名，补一句备注即可 |
| **多线程友好** | 可同时挂多个任务，按到期时间自动排序，最紧急的排最上；到期任务红色醒目 + 顶部提示条，一眼看到 |
| **两层到点提醒** | 图标角标显示到期任务数（绿=倒计时中 / 红=已过期）→ 鼠标移上去自动展开看到详情；过期后每 5 分钟重复提醒 |
| **三态任务库** | 进行中 / 已完成 / 已删除三部分：误点完成可恢复、误删可在"已删除"找回、完成的任务还能重新激活，不用重复新建 |
| **深/浅色主题跟随系统** | 全套配色（背景/文字/边框/强调色）联动 Windows 深色/浅色主题，不存在"只变背景、文字看不清"的问题 |
| **便携免安装** | 单个文件夹解压即用：无安装、无注册表污染、不常驻开机（可设置）；数据存在本机，不联网 |
| **安全可靠** | 删除有确认框，误操作可恢复；数据文件损坏自动容错；单实例运行不打架 |

## 三、能实现什么功能

### 任务管理
- **新建任务**：双击任务列表空白处，或点标题栏"＋"；自动填入上一个操作的软件名称，可加备注
- **时长选择**：5 / 10 / 15 / 30 / 60 分钟，或自定义任意时长
- **稍后提醒**：任务到点但暂时不想处理 → 点"稍后"，可选 5 / 10 / 15 / 30 分钟，重新计时
- **完成任务**：点任务行"✓"，进入"已完成"库（可重新激活）
- **恢复与删除**：已完成可恢复成进行中；删除进"已删除"（可找回），也可彻底删除

### 提醒机制
- **三态自动收起**：默认无操作 5 分钟 → 半透明（不打扰浏览）；再过 30 秒 → 收成桌面小图标；所有时长与透明度可在设置中自定义
- **半透明即激活**：鼠标移到界面上立即恢复清晰，可直接操作
- **到点提醒**：图标角标显示数字 → 鼠标移上去展开界面看到是哪几项 → 过期任务每 5 分钟提醒一次
- **任务状态用颜色区分**：绿色字体/圆点 = 倒计时中；红色字体/圆点 = 已过期未处理

### 界面交互
- **标题栏整行可拖拽**（按住的任意空白处都能拖动窗口）
- **右下角热区调整窗口大小**（其余区域不会误触）
- **按任务数量自适应高度**，任务多时自动展开，长内容自动换行
- **圆形图标 + 右侧倒计时小标签**：没任务时是纯圆形；有任务时右侧伸出标签显示最近到期任务的倒计时

### 系统集成
- 托盘常驻：右键菜单（打开主界面 / 新建任务 / 设置 / 关于 / 退出），双击托盘图标打开主界面
- 开机自启（可选，默认关闭）
- 记忆窗口位置（异常退出/屏幕变化也不会把窗口丢到屏幕外）
- 深色/浅色主题跟随 Windows 系统

## 四、快速上手（便携版）

1. 下载 zip 压缩包，解压到任意文件夹（如 `D:\DesktopReminder`）
2. 双击 `DesktopReminder.exe` 即可使用，无需安装
3. 数据保存在程序同目录 `data` 文件夹（`tasks.json` / `settings.json` / `app_names.json`），删除整个文件夹即完成卸载

## 五、技术架构

四层单向依赖（改一处不影响其他层）：

```
表现层 UI（WPF）         只画界面、收点击，不写业务判断
    ↓
应用层 Core             窗口三态状态机、任务调度、提醒
    ↓
领域层 Domain           任务模型、到期/排序/倒计时计算（纯逻辑，57 个单元测试覆盖）
    ↓
基础设施 Infrastructure Windows 前台窗口识别、持久化、日志
```

- 领域层是**纯静态函数**，不依赖界面与存储，可独立单测——这是"改一处不冒出新 bug"的根基
- 主题通过 DynamicResource 全树刷新，深/浅色切换一次到位
